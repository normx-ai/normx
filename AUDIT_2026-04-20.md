# Audit Normx — 2026-04-20

Application React 19 + Express + PostgreSQL + Qdrant (comptabilité, paie, états, révision, assistant IA).
Audit réalisé avant correction sur trois axes : sécurité, performance, duplication de code.

---

## 1. Sécurité

### Critique

- JWT payload décodé sans vérification d'expiration via `Buffer.from(...base64)`
  - `server/routes/auth.ts:62` (`/api/auth/callback`)
  - `server/routes/auth.ts:117` (`/api/auth/refresh`)
  - `server/routes/auth.ts:170` (`/api/auth/me`)
  - Correction : `jwt.decode(token, { complete: true })` + contrôle `exp` avant retour au client.

- XSS via `dangerouslySetInnerHTML` sur exports Excel (variables `entiteName`, `entiteNif`, `title`, `subtitle` non échappées)
  - `src/etats/ResultatFiscal.tsx:597`
  - `src/etats/CompteResultatSYSCOHADA.tsx:576`
  - `src/etats/TFT_SYSCOHADA.tsx:620`
  - `src/etats/BilanSYSCOHADA.tsx:441`
  - Helper concerné : `src/lib/excelExport.ts` (`buildExcelPreviewHtml`, l. 230-297)
  - Correction : échappement HTML (`&`, `<`, `>`, `"`, `'`) ou DOMPurify.

- Cookie CSRF `httpOnly: false` lisible par tout script
  - `server/middleware/csrf.ts:22`
  - Correction : `httpOnly: true`, exposer le token via un endpoint dédié ou header de réponse.

### Haute

- DB SSL désactivé par défaut en production
  - `server/db.ts:10` (`const sslEnabled = process.env.DB_SSL === 'true'`)
  - Correction : `ssl: true` par défaut en prod, opt-out explicite pour dev local.

- Message d'erreur verbeux sur `ANTHROPIC_API_KEY`
  - `server/services/assistant.chat.ts:11-12`
  - `server/services/ocr-import.service.ts:13-14`
  - Correction : validation au startup, erreur générique côté client.

### Moyenne

- Stack trace loggée avec message client vague (comportement correct, mais vérifier que les logs ne quittent jamais le serveur).
  - `server/index.ts:213-215`

- CORS fallback sur `localhost:3000/3001` si `ALLOWED_ORIGINS` non défini ; ajouter une garde anti-`*`.
  - `server/index.ts:69-77`

### Propre

SQL paramétré partout, Helmet configuré, rate limit auth 10/h, JWT RS256 via JWKS Keycloak, Multer avec magic bytes, pas d'`eval`, cookies d'accès/refresh `httpOnly: true`, jsonwebtoken 9, helmet 8.

## 2. Performance

### Critique

- Pagination absente ou `LIMIT 5000` hardcodé
  - `server/services/ecritures.service.ts:360` (`getGrandLivreTiers`)
  - `server/services/ecritures.service.ts:484` (`getBalanceAgee`)
  - `server/services/ecritures.service.ts:607` (`getEcheancier`)
  - Correction : pagination `limit/offset` paramétrable côté API.

- Import TVA : deux `SELECT` massifs sur comptes 443x/445x puis calculs JS
  - `server/services/tva.service.ts:354-400`
  - Correction : filtrer et calculer le net (`montant_taxe / taux`) directement en SQL.

### Important

- Calculs Bilan sans `useMemo` (re-render 500 ms CPU)
  - `src/etats/BilanSMT.tsx:154-159` (`computeResultatNet`, `computeActif`, `computePassif`)
  - Correction : `useMemo([lignesN, lignesN1])`.

- `readFileSync` runtime sur KB et templates SQL
  - `server/services/assistant.agents.ts` (KB JSON)
  - `server/services/tenant.service.ts` (template SQL)
  - Correction : chargement unique au startup + cache, sinon `fs/promises`.

- Qdrant + fallback KB séquentiels
  - `server/services/assistant.chat.ts:77-81`
  - Correction : `Promise.race` avec timeout Qdrant 2 s.

- Index listés dans migrations 003-005 mais absents de `sql/schema.sql`
  - Les nouveaux tenants créés à partir du schéma de base sont dépourvus d'index.
  - Correction : intégrer les `CREATE INDEX` dans `schema.sql`.

### Mineur

- `recalcTotals` TVA refait un `SUM` à chaque addLigne/updateLigne
  - `server/services/tva.service.ts:41-62, 214, 269, 302`
- Styles inline dans tables volumineuses
  - `src/etats/BilanSMT.tsx:190-200`
- Plan comptable : `staleTime` React Query trop court
  - `src/etats/ImportBalanceTable.tsx:33-37` → `staleTime: 24*60*60*1000`.

### Propre

React Query, bulk inserts paramétrés, pagination correcte sur écritures et balance principale, pas de lodash/moment massifs, transactions ACID aux bons endroits.

## 3. Duplication de code

### Haute

- 72 vérifications `if (!schema) return res.status(400).json({ error: 'Contexte tenant manquant.' })` répétées dans toutes les routes
  - `server/routes/balance.ts` (10)
  - `server/routes/ecritures.ts` (20)
  - `server/routes/tva.ts` (9)
  - `server/routes/paie.ts` (10)
  - `server/routes/tiers.ts` (7)
  - `server/routes/rubriques.ts` (6)
  - `server/routes/revision.ts` (3)
  - `server/routes/notifications.ts` (6)
  - Correction : middleware `requireTenantSchema` + généralisation de `asyncHandler`.

- Quatre implémentations de `formatMontant`
  - `src/etats/ImportBalance.parsers.ts:130`
  - `src/etats/bilan/bilanSyscohadaCompute.ts:7`
  - `src/etats/TFT_helpers.ts:52`
  - `src/paie/utils/calculPaie.ts:147` (`formaterMontant`)
  - Correction : module `src/utils/formatters.ts` centralisé.

- Pattern `fetch + setLoading + try/catch silencieux` dans 50+ composants
  - Exemples : `src/comptabilite/TiersPage.tsx:123-134`, `ImportDocumentModal.tsx`, `Journaux.tsx`, `GrandLivre.tsx`, tous les `src/etats/notes/Note*.tsx`.
  - Variante `useQuery` quasi-identique dans 20+ composants (ex. `SaisieJournal.tsx:85-96`).
  - Correction : hook générique `useFetchEntity<T>` + normalisation (`Array | { data } | { tiers }`).

### Moyenne

- `interface PlanCompte` / `CompteComptable` dupliquée
  - `server/routes/ecritures.ts:8-10`
  - `server/routes/tva.ts:7-10`
  - `server/routes/planComptable.ts:6-10`
  - Correction : `server/types/comptes.ts`.

- Endpoints API en dur (~255 occurrences)
  - Correction : `src/constants/apiEndpoints.ts`.

- `formatDate` dupliquée
  - `src/components/NotificationBell.tsx:76`
  - `src/assistant/AssistantChat.tsx:265`

### Basse

- Taux IS (28/25/33/1 %) et IBA (30/1,5 %) en dur dans `src/etats/ResultatFiscal.tsx` — à centraliser dans `src/constants/taxation.ts`.

### Propre

Schémas Zod bien centralisés dans `server/schemas/` ; configuration API isolée dans `src/lib/api.ts`.

## Plan d'attaque proposé

### Sprint 1 — sécurité + quick wins

1. Vérification `exp` JWT sur `/me`, `/callback`, `/refresh`.
2. Escape HTML dans `buildExcelPreviewHtml` (entiteName, title, subtitle, entiteNif).
3. `httpOnly: true` sur cookie CSRF + ajustement frontend.
4. `ssl: true` par défaut en production.
5. `useMemo` sur calculs Bilan.
6. `staleTime` long sur plan comptable.

### Sprint 2 — refonte

1. Middleware `requireTenantSchema` + `asyncHandler` généralisé.
2. `src/utils/formatters.ts` + remplacement des 4 `formatMontant`.
3. Hook `useFetchEntity<T>` et migration progressive des composants.
4. Pagination Grand livre / Balance âgée / Échéancier.
5. Intégration des `CREATE INDEX` dans `sql/schema.sql`.
6. `src/constants/apiEndpoints.ts` et `src/constants/taxation.ts`.

- Performance : gain ×3 à ×5 sur requêtes balance/TVA après pagination et calculs SQL.
- Sécurité : 3 critiques + 2 hautes à corriger avant toute mise en prod supplémentaire.
